# To-Do List App

A simple task manager built with plain HTML, CSS and JavaScript (no frameworks).

## Features
- Add, complete and delete tasks
- Filter by All, Active or Done
- Shows how many tasks are left
- Tasks are saved in the browser (localStorage), so they stay after a refresh

## How to run
Open `index.html` in any browser. No installation needed.

## What I learned
- Selecting and changing page elements with the DOM
- Handling events (submit, click, change)
- Working with arrays: `filter`, `forEach`, `push`
- Saving data with `localStorage` and `JSON`
- Keeping the screen in sync with data by re-rendering from one `tasks` array
